# Analysis Types

Change the research and the reporting to match the selected type. `[YEAR]` is the current calendar year. Do not include report sections that are irrelevant to the selected type.

---

## Type 1 — Negative Sentiment (default)

**Objective:** determine what players are most unhappy about in [YEAR].

**Analyze:** overall sentiment, negative themes, major complaints, repeated complaints, unpopular updates, player frustration, bugs, missing features, QoL complaints, event dissatisfaction, balance concerns, monetization complaints, community backlash, emerging issues, sentiment changes over time.

**Primary question:** What are players most unhappy about in [YEAR]?

**Do NOT automatically analyze** revenue, spending reduction, purchase refusal, F2P migration or subscription cancellation unless explicitly requested.

---

## Type 2 — Update / Patch Feedback

**Analyze:** major [YEAR] updates, patch notes, new features, removed features, balance changes, new characters, new systems, community reaction (positive and negative), update-specific complaints, post-update sentiment, requests for future patches.

**Primary question:** How is the community reacting to the game's [YEAR] updates?

Where enough dated evidence exists, compare sentiment before and after important updates.

---

## Type 3 — Bugs & Technical Issues

**Analyze:** crashes, freezes, lag, server problems, login problems, disconnects, loading problems, performance, optimization, device compatibility, UI bugs, broken mechanics, game-breaking issues.

**For every major technical issue assess:** frequency, recency, severity, platforms affected, whether multiple sources report it, whether developers acknowledged it, whether a fix appears to exist.

**Primary question:** What technical problems are players experiencing in [YEAR]?

---

## Type 4 — Missing Features / QoL

**Analyze:** feature requests, missing features, removed features, QoL complaints, UI/UX requests, accessibility, automation requests, repetitive gameplay, inventory problems, navigation problems, community-requested improvements.

**Rank issues using:** frequency, recency, cross-platform presence, community intensity, product importance.

**Primary question:** What features or QoL improvements are players asking for?

---

## Type 5 — Monetization Feedback

**Analyze:** pricing, bundles, packs, battle passes, subscriptions, currency, rewards, drop rates, pay-to-win, FOMO, value perception, monetization changes, whaling, cash-grab complaints.

**Primary question:** How does the community perceive the game's monetization?

This does **not** automatically mean analyzing whether spending changed.

---

## Type 6 — Player Spending Impact

**Run only when explicitly requested** (see the Spending guardrail in `SKILL.md`).

**Analyze whether players explicitly report:** stopping purchases, reducing spending, refusing purchases, refusing shard packs, refusing bundles, cancelling subscriptions, avoiding battle passes, becoming F2P, quitting, uninstalling, moving to another game, taking a spending break.

**Classify each piece of evidence as:**

| Class | Meaning |
|---|---|
| **Explicit Spending Evidence** | The player directly states that an issue changed their spending. |
| **Indirect Spending Signal** | The issue concerns monetization, but the player does not explicitly report a spending change. |
| **No Spending Evidence** | Negative feedback exists, but there is no meaningful evidence connecting it to spending. |

Keep explicit and indirect evidence separated in the report.

**Then assess:**
- *Likelihood that sentiment affected paying behavior:* High / Medium / Low / Unknown
- *Confidence:* High / Medium / Low

**Critical rule:** never interpret "I hate this update" as "this update reduced spending." There must be evidence. Social evidence alone cannot establish revenue, ARPU, conversion, purchase or churn changes (see the Causality guardrail in `SKILL.md`).

**Primary question:** Is there credible community evidence that negative sentiment is affecting player spending behavior?

---

## Type 7 — Balance / Competitive Issues

**Analyze:** power creep, PvP, PvE, arena modes, matchmaking, meta, character balance, overpowered characters, underpowered characters, competitive fairness, pay-to-win advantage, competitive progression.

**Primary question:** What balance and competitive issues are driving player dissatisfaction?

---

## Type 8 — Event Feedback

**Analyze:** event design, difficulty, rewards, frequency, duration, FOMO, event monetization, event bugs, player frustration, player appreciation.

**Primary question:** Which events are generating positive or negative player reactions, and why?

---

## Type 9 — Custom Analysis

If the user specifies their own research question:

- Follow the exact requested scope.
- Create an appropriate methodology.
- Do not force the analysis into the standard categories.
- Preserve the analysis-period restriction unless the user explicitly changes it.
