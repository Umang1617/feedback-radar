# Search Guide

`[GAME]` is the game name and `[YEAR]` is the current calendar year. Use platform-specific searches where indexing supports them.

## Data sources

Search publicly accessible information only.

| Platform | What to look at |
|---|---|
| **Web** | Gaming websites, game news, patch notes, developer announcements, official blogs, public forums, community websites, public reviews, search results, Google AI Overviews where available |
| **Reddit** | Posts, comments where accessible, subreddits, megathreads, update discussions, community reactions |
| **YouTube** | Videos, titles, descriptions, public comments where accessible, reviews, update reactions, complaint videos, community videos |
| **X / Twitter** | Public posts, public replies where accessible, developer posts, game-account posts, community posts |
| **Facebook** | Public posts, public pages, public groups, public comments where accessible |
| **Instagram** | Public posts, reels, captions, public comments where accessible |

Required minimum: Reddit, YouTube, X/Twitter and the general web. Facebook and Instagram when relevant publicly indexed content is available.

**Missing Features / QoL**

For the other types, adapt the same pattern using the keywords below.

## Keyword library

**Sentiment:** bad update, terrible update, disappointing, frustrated, angry, backlash, boycott, worst update, unhappy, disappointed

**Technical:** crash, crashing, bug, broken, lag, freeze, disconnect, server, loading, performance, optimization

**QoL:** missing feature, feature request, QoL, quality of life, bring back, removed, remove, request, wishlist

**Balance:** power creep, OP, overpowered, underpowered, balance, meta, PvP, Arena, matchmaking

**Monetization:** expensive, overpriced, monetization, pay to win, P2W, whale, cash grab, bundle, pack, battle pass, subscription

**Spending** (use ONLY when spending analysis is selected): stop spending, stopped spending, spending less, no more purchases, refuse packs, refusing shard packs, F2P, free to play, quit, uninstall, cancelled subscription
